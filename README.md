# AAT Call Center Report Analysis Tool

This tool is designed to analyze call center reports, specifically daily performance PDFs and pure abandoned Excel logs.

## Features
- KPI Dashboard
- - Hourly Analysis
  - - Service-wise breakdown
    - - Erlang Staffing Model for Agent Requirements
      - - CEO Summary Generation (Export to Word)
        - - Universal Exports (Excel, PNG)
         
          - ## Installation
          - 1. Install dependencies: `pip install -r requirements.txt`
            2. 2. Run the app: `streamlit run app.py`
